三条根本性设计原则
在写任何具体规则之前，先确立不可违背的哲学基础
原则一 · 风险管理先于收益追求
永远不做让自己"输不起"的操作
A股单股政策风险、隔夜跌停风险是客观存在的结构性约束，无法通过更好的系统消除，只能通过仓位定价和分散来吸收。任何一笔交易的最坏结果，必须是账户可以承受并继续正常运作的。这意味着：任何单一持仓的最大可能亏损（包含隔夜缺口风险）≤ 总资金的3%。这条约束决定仓位上限，而不是反过来。
原则二 · 机械执行先于主观判断
人工干预只能让系统更保守，不能让它更激进
前两版暴露的最大执行漏洞是：人工确认环节在极端情绪下会系统性地推翻正确决策。解决方案不是消除人工干预，而是明确划定人工干预的边界：可以拒绝开仓（只做更保守的选择），可以提前止损（只让风险更小），但不能延迟已触发的机械止损，不能在熔断期内加仓。规则是在情绪平静时制定的，必须在情绪激动时执行。
原则三 · 简单参数先于精确优化
参数来自逻辑推导，而非历史数据拟合
止损-8%是因为"A股日内波动约1.5%，允许4-5天整理期的误差"，而不是因为回测时-8%比-7%或-9%效果更好。所有参数必须能用一句话解释其逻辑来源，且经过±20%敏感性测试：参数变化20%，策略结论不应根本性改变。满足这两个条件的参数才是稳健的，否则是过拟合。

市场状态引擎
三状态判定，新增小盘/大盘解耦因子，区分"涨的是谁"

V1/V2最大批评之一：指标太笼统，没有区分上涨的真实原因。银行股拉动大盘突破20日线，与小盘科技股获得主力资金介入，是完全不同的市场环境，但前两版的引擎给出相同的"绿灯"信号。V3增加F2"小盘/大盘解耦度"作为核心区分因子。

资金质量识别层
区分机构建仓、游资炒作、散户追高三种上涨性质

这是V3新增的核心层，直接回应"指标太笼统，没有区分上涨真实原因"的批评。同样是涨停+缺口+缩量整理，如果整理期间大单净流入为正（机构悄悄吸筹），后续主升行情的概率远高于大单出货期间散单勉强撑价的情形。

数据获取方式

方式A：AkShare个股资金流向

接口：ak.stock_individual_fund_flow(symbol)

字段：超大单净买入、大单净买入、中单、小单净买入（元）。取整理期（涨停后2-7日）的大单净买入额 / 同期总成交额，得到大单占比。

优点：免费，每日更新。局限：T+1发布，无法盘中参考。

方式B：龙虎榜席位判断

接口：ak.stock_lhb_detail_em(date)

若涨停当日或次日出现机构专用席位（"机构席位"），性质升级为机构主导，D2直接加5分；若出现多个游资席位，保持中性评分。

优点：直接识别机构参与。局限：只有涨停日才有龙虎榜。

ℹ️
整理期内连续3日大单净卖出，无论其他评分多高，该候选直接从当日列表移除。这不是评分降低，而是性质判断失败——持仓主体在出货，不应该接盘。

选股系统 V3
技术形态初筛 → 负面过滤 → 量化评分（AI移出）→ 行业分散检查

技术形态初筛（条件不变，定义更精确）

①
近15个交易日内出现第1次（且不超过2次）涨停 涨停 = 收盘涨幅 ≥ 9.9%。排除：连续涨停（超过2次连板）；ST股的±5%。"近15日"而非20日：缩短窗口过滤掉时机已过的信号。
②
涨停次日开盘价 > 涨停当日最高价，且跳空缺口5日内未完全回补 跳空缺口体现主力不急于回补的控盘意图。"5日未完全回补"：回补定义为任意收盘价 ≤ 涨停当日最高价。
③
缺口上方缩量整理2-7天 整理期日均量 ≤ 涨停日量的50%（比V2的60%更严格）；整理期内无收盘新高（出现新高说明已启动，失去低吸时机）。
④
所属板块动能加速度排名前15 加速度 = 近3日板块涨幅 / 近10日板块涨幅。取全市场板块加速度前15名，确保股票所在板块正在加速而非已经见顶。

行业分散硬约束（回应批评③：持仓集中度）

⚡
前两版最被批评的结构性问题之一：可能同时持有3支AI板块股票，本质是一个押注，而非分散。行业相关性在板块轮动时会同时崩溃。
硬规则 同一申万一级行业，最多同时持有1个仓位。
例：已持有"电子"板块A股，系统不得再推荐同属"电子"的候选股，即使其评分更高。评分排名第2的候选中，如果行业不冲突，优先选入。

行业归属通过 ak.stock_board_industry_cons_em(symbol) 或 Tushare stock_basic 的 industry 字段获取，每日自动检查持仓行业分布。

负面过滤器（一票否决，不变）

  • ST / *ST / 退市警示（自动排除）
  • 有效减持计划执行期内（Tushare）
  • 商誉/净资产 > 40%（年报季 > 35%）
  • 近30日有业绩预减/预亏公告
  • 上市不足12个月
  • 整理期连续3日大单净卖出（新增）

仓位定价模型
从"固定30%"改为基于风险预算和缺口概率的动态定仓
⚠️
前两版批评：固定30%仓位没有考虑A股缺口风险。当股票因负面消息跳空-10%开盘时，你的计划止损-6%已经失效，实际亏损比预期大40%以上。正确做法是把缺口风险定价进仓位大小，而不是假装它不存在。

仓位定价公式

// 目标：每笔交易最坏情况下，亏损不超过总资金的2% 计划止损距离 = 8% // 从入场收盘价，基于逻辑（4-5日正常波动容错） 缺口风险倍数 = 1.5 // 实际亏损可能是计划的1.5倍（隔夜跳空 -10% 很常见） 预期最大亏损 = 8% × 1.5 = 12% // 每笔交易预期最坏情况 单笔风险预算 = 总资金 × 2% // 每笔最多亏2%总资金 仓位比例 = 单笔风险预算 / 预期最大亏损 = 2% / 12% = 16.7% → 取整为 15%（保守取整） // 即：每个仓位最大15%，而非固定30% // 进攻状态最多8支×15% = 120% 理论值，实际总仓位上限80% // 观望状态最多4支×12% = 48%，留出足够现金缓冲

波动率调整（高波期自动缩仓）

当日个股ATR / 20日均ATR仓位系数实际仓位上限说明
< 0.8（低波）1.2×min(18%, 状态上限)低波期可略加仓
0.8 - 1.3（正常）1.0×标准仓位标准执行
1.3 - 2.0（高波）0.7×标准仓位 × 70%波动扩大，自动缩仓
> 2.0（极端波动）0.5×标准仓位 × 50%极端波动，大幅缩仓
✅
这个定仓模型解决了两个问题：① 缺口风险被定价进仓位（不假装-6%止损一定能执行）；② 波动率自动调整意味着高风险期系统自我收缩，而非等到账户亏损后被迫熔断。这从根本上减少了熔断被误触发的概率。

分级入场规则
状态决定入场窗口宽度，盘中二次确认降低踏空概率

前版批评：入场条件太死板，容易踏空强势股。V3的解决思路不是无限制追高，而是用市场状态决定容忍度，同时增加盘中二次入场机制应对跳空情形。

主入场（次日开盘，T+1合规）

市场状态开盘入场窗口买入比例逻辑
进攻开盘价在昨收 ±3% 以内计划仓位的 1/2进攻期放宽至±3%，捕捉强势跳空小缺口
观望开盘价在昨收 ±2% 以内计划仓位的 1/2观望期收窄，谨慎入场
防守禁止新开仓—防守期无论多好的信号都不开新仓

盘中二次入场（应对错过主入场的情形）

ℹ️
如果开盘跳空超出入场窗口（如大幅高开+5%），主入场放弃。但股票并非必然失去机会——若盘中回落至昨收+1.5%以内，且回落过程中量能萎缩（缩量回调而非放量出货），可视为二次买点。
条件要求执行
价格回落盘中价格回落至昨收 +1.5% 以内（仅在开盘高开超出窗口后适用）满足全部条件 → 买入计划仓位1/2

不满足任一 → 放弃当日，次日重新评估
时间窗口发生在开盘后 前90分钟 以内（9:30-11:00）
量能验证回落期间分时成交量 < 同期5日均量（说明是缩量回调，非出货）

加仓确认（建立初始仓位后）

  • 股价放量突破整理平台上沿：当日成交量 > 5日均量 × 1.3，且收盘创整理期新高
  • 次日开盘不低于突破日收盘 -1%（确认不是假突破）
  • 满足以上两条：次日追加至完整仓位（加入剩余1/2）
  • 加仓后成本价更新，所有止损线同步重新计算
07
止损体系
宽止损 + 小仓位，而非窄止损 + 大仓位
⚠️
核心认知修正：A股T+1制度下，止损的本质不是"在恰好-6%时卖出"，而是"在状态确认破坏后的第一个可执行时间点离场"。止损线宽（-8%）+ 仓位小（≤15%）= 最大亏损可控（-8% × 15% = -1.2%总资金），同时给予足够的整理容忍度。
止损类型触发条件（精确量化）T+1执行方式
价格止损 任意收盘日，收盘价 < 入场日收盘价 × 0.92
(止损 -8%，设为-8%的逻辑：A股日内波动约1.5%，允许4日正常误差3×1.5%≈5%，加上缺口容错=8%)		 确认日（D）收盘触发 → D+1日开盘前5分钟挂单（不等到9:25竞价，提前挂出比前日收盘低2%的限价卖单，确保快速成交）
时间止损 入场后 8个交易日，收盘价涨幅 < 5%
(8日是因为正常整理期2-7天，加1天容错；5%是覆盖建仓手续费后的最低确认信号)		 第8日收盘确认触发 → 第9日开盘卖出，无需等待更好价格
形态止损 技术形态完全破坏：缺口被完全回补（收盘价 ≤ 涨停当日最高价） 形态破坏日收盘确认 → 次日开盘止损。策略的选股逻辑已失效，缺口消失意味着此轮行情分析错误。
事件止损 持仓期间出现：① 新增减持公告；② 监管问询函；③ 业绩预减 > 50%；④ 临时停牌超2日 公告当日确认 → 次日开盘无条件止损，不管当时浮盈/浮亏如何

缺口风险的诚实评估

前版批评说得准确：止损挂次日开盘，实际亏损会远大于计划。这个问题无法通过系统设计完全消除，只能管理。V3的处理方式是：

  • 在仓位定价时已将缺口倍数（1.5×）纳入计算，接受"最坏情况-12%"
  • 绝不持有临近重大事件（财报、监管听证、央行决议）的仓位过夜
  • 绝不在已有负面信号（减持计划公告、商誉警告）后继续持有
  • 缺口风险是A股的结构性成本，接受它，而不是用更复杂的规则假装能规避

状态熔断机制
用"市场状态变化"触发熔断，而非"账户已经亏损多少"
⚠️
根本性重设计：V1/V2批评最强烈的两个问题——"熔断线与A股波动不匹配"和"熔断在连续下跌中加速亏损"——都源于同一个设计错误：用账户P&L的后验指标来触发风险减量操作。更好的逻辑是：当市场状态本身恶化时（前向指标），主动减仓；而不是等到账户已经亏损后（后验指标），被迫卖在最低点。

  • 当日收盘计算，即时生效
  • 不需要持续确认（单日切换即触发）
    • 强制动作
  • 次日起：禁止开任何新仓
  • 所有止损线提高一档（如：在用20日MA的提升至10日MA）
  • 暂停所有加仓计划

    触发条件

  • OR：连续2个交易日维持观望状态（40-55分）且有下行趋势
  • 当日收盘即触发
    • 强制动作
  • 在2个交易日内，卖出评分最低的50%持仓
  • （允许2日分散卖出，避免同时砸盘）
  • 剩余仓位止损全部上移至成本价以上
  • 等待状态恢复至观望后才重新评估

    • L3 · 全面撤退（防守状态持续3日）

    触发条件
  • 状态引擎连续3个交易日维持防守（<40分）
  • 第3日收盘确认触发

  • 3个交易日内完成全部清仓
  • （分3天执行，避免集中踩踏自己的仓位）
  • 强制空仓观察期：10个交易日

    def calc_position_size(total_capital: float, symbol: str, state_grade: str) -> float: # 基础仓位上限（来自市场状态） base_limit = {"进攻": 0.15, "观望": 0.12, "防守": 0.0}[state_grade] # 风险预算定仓 risk_budget_pct = 0.02 # 每笔最多亏2%总资金 stop_distance = 0.08 # 止损 -8% gap_multiplier = 1.5 # 缺口风险倍数 risk_based_pos = risk_budget_pct / (stop_distance * gap_multiplier) # = 16.7% # 取较小值（风险预算 vs 状态上限） base_pos = min(risk_based_pos, base_limit) # 波动率调整 hist = ak.stock_zh_a_hist(symbol=symbol, period="daily", adjust="qfq").tail(25) hist["atr"] = (hist["最高"] - hist["最低"]) / hist["收盘"] atr_ratio = hist["atr"].iloc[-1] / hist["atr"].tail(20).mean() vol_factor = 1.2 if atr_ratio < 0.8 else 1.0 if atr_ratio < 1.3 else 0.7 if atr_ratio < 2.0 else 0.5 final_pos_pct = min(base_pos * vol_factor, base_limit) final_pos_amt = total_capital * final_pos_pct return round(final_pos_pct, 4), int(final_pos_amt)

    铁律红线
    永不触碰的边界，无论市场给出多强的诱惑
    RL-01 防守状态下，禁止任何新开仓，无论信号评分多高。
    市场状态决定策略开关，不是信号质量。在市场结构性下行时，再好的个股信号也只是在错误的时间做对的事。
    RL-02 已触发的价格止损和时间止损，T+1内必须执行，无任何延迟理由。
    "感觉会反弹"不是理由。"明天可能有好消息"不是理由。止损是在平静时做出的理性决定，必须在情绪激动时机械执行。
    RL-03 整理期大单净卖出的候选，不得入场，无论图形多完美。
    技术图形是过去的轨迹，资金性质是当下的意图。当持仓主体在悄悄出货，技术形态是给散户看的。
    RL-04 同一申万一级行业不得同时持有2个仓位，无例外。
    再好的第二支同行业股票也不能突破这条规则。行业集中的代价在板块轮动时才会显现，届时后悔已晚。
    RL-05 L3空仓期（10个交易日）内，不得因"行情太好"提前重新入场。
    L3触发时市场已经连续3天防守状态。急于回场通常是在恐慌低点之后的第一次反弹时FOMO入场，恰好是再次被套的最佳时机。
    RL-06 单笔交易在最坏情况下，亏损不超过总资金3%（含缺口风险）。
    仓位定价公式的存在意义正在于此。如果一笔交易"感觉太好"而想突破仓位上限，这是贪婪，不是判断。
    RL-07 任何参数调整都需要逻辑理由和敏感性测试，不得基于最近几笔交易的表现进行微调。
    最近几笔盈亏是噪声而非信号。根据噪声调整参数，等于在用历史数据过拟合未来。参数保持3个月以上稳定才有意义。
