1.2 0DTE革命（2022至今）

🔥 0DTE改变了什么？
  • 交易量：0DTE占SPX期权交易量从2021年的~20%升至2024年的50%+
  • 微观结构：日内Gamma在最后几小时趋向无穷大，Theta加速衰减
  • Dealer行为：0DTE的Gamma暴露迫使Dealer在日内频繁对冲，成为价格主要驱动力
  • 因子影响：传统基于月度期权的因子（如30D IV）在短端信息含量下降；需要新的0DTE专属因子
  • 策略影响：卖0DTE的Gamma风险极大（最后几小时Gamma爆炸），传统"卖期权收Theta"需要重新评估
  • 扩展：从SPX扩展到NVDA、TSLA、AAPL等大市值个股

2.1 Black-Scholes-Merton与完整Greeks体系

C = S·N(d₁) − K·e−rT·N(d₂)

2.2 美式期权定价（美股个股期权特有）

🔴 为什么不能用欧式BSM？

美股个股期权是美式（American Style），支持提前行权。深度ITM的Call（尤其是有股息的标的）可能被提前行权。直接使用欧式公式会低估期权价值、错算Greeks。

模型方法速度精度适用场景
Bjerksund-Stensland (2002)解析近似（行使边界近似）极快高大规模Greeks计算（首选）
Barone-Adesi & Whaley (1987)二次近似快中高快速定价
CRR二叉树离散时间动态规划慢精确精确验证、奇异期权
Longstaff-Schwartz (LSM)蒙特卡洛 + 最小二乘回归中高多因子、路径依赖

校准要点：

  • 无风险利率：使用SOFR曲线（替代LIBOR），按到期日插值
  • 借贷成本：Hard-to-Borrow Rate（做空成本）影响Put-Call Parity
  • 股息：预期派息日期和金额，影响早期行权决策
  • 提前行权判断：深度ITM + 即将除息 → 高概率提前行权

2.3 IV · RV · VRP 详解

隐含波动率（IV）的计算

给定市场价格 Cmkt，求解 σ 使得：
CBSM(S, K, T, r, σ) = Cmkt

数值方法：Newton-Raphson / Brent's Method / Bisection

已实现波动率（RV）的多种估计

估计方法公式特点
Close-to-CloseRV = √(252/N · Σ ln(St/St-1)²)最常用，但忽略日内信息
ParkinsonRV = √(1/(4N·ln2) · Σ (ln(H/L))²) × √252利用High/Low，效率提升5倍
Garman-KlassRV = √(1/N · Σ [½(ln(H/L))² − (2ln2−1)(ln(C/O))²]) × √252利用OHLC，效率提升8倍
Yang-Zhang结合开盘跳空处理隔夜跳空
已实现方差（高频）RV = Σ rt,i²（日内分钟收益）最精确，需高频数据

波动率风险溢价（VRP）

VRP = IV − RVforward
VRPratio = IV / RV − 1
Variance Risk Premium = VIX²/10000 − E[RV²]
✅ VRP的实证特征
  • IV长期系统性高于RV，年化溢价约3–5个波动率点
  • VRP在高IV环境中更大（恐慌时保险溢价更高）
  • VRP在低IV环境中被压缩（拥挤）
  • IV/HV比率偏高后：20天后低于基准−0.29%，30天后−0.72%
  • IV Rank和IV Percentile未显示可靠预测能力（Walter et al., 2026）

3.2 SVI模型详解

SVI参数化（Gatheral, 2004）：

w(k) = a + b · [ρ(k − m) + √((k − m)² + σ²)]

其中 w = σ²T（总方差），k = ln(K/F)（对数行权价）
参数：a（水平）, b（斜率）, ρ（旋转）, m（平移）, σ（ATM曲率）

无套利约束：

  • Butterfly无套利：∂²C/∂K² ≥ 0（密度非负）
  • Calendar无套利：∂w/∂T ≥ 0（总方差随到期日递增）
  • Gatheral条件：确保拟合曲线不产生套利机会

SABR模型

dF = σFβ dW₁
dσ = ασ dW₂
dW₁·dW₂ = ρ dt

参数：α（初始波动率）, β（CEV指数）, ρ（相关性）, ν（Vol-of-Vol）
💡 SVI vs SABR 选择
  • SVI：截面拟合（同一到期日不同Strike），提取纯净Total Variance Curve
  • SABR：动态建模（波动率随时间演变），计算平滑Greeks
  • 实践中常结合使用：SVI拟合曲面 → SABR平滑动态

5.2 期权因子与股票因子的关系

🔴 核心实证发现（Walter, Zimmer & Ulrich, 2026）

使用Feng, Giglio & Xiu (2020)的双重选择LASSO方法：

  • 样本内，股票因子解释了约91%的期权因子方差
  • 加入期权因子并未显著提高最大夏普比率
  • 但8个期权因子在控制股票因子后仍有非零SDF载荷
  • 4个因子在Bonferroni校正后依然显著

核心启示：期权市场增加的是少数几个定价相关的维度，而非一个全新的因子动物园。应聚焦于期权因子的增量信息（跳跃尾部、峰度、IV凸性），而非独立构建一套期权因子体系。

6.3 Alpha与Beta（期权版）

期权收益 = 结构性波动率风险溢价 (Vol Beta) + 曲面错价与微观Alpha (Vol Alpha)

📊 期权Beta（Smart Beta / Vol Risk Premia）

  • 定义：承担结构性风险的补偿
  • 代表：Short VRP（卖跨/卖宽跨/CSP/CC）
  • 特点：胜率80%+，胖尾分布
  • 容量：极大（数百亿）
  • 衰减：极慢（结构性存在）

🎯 期权Alpha（Vol Relative Value）

  • 定义：定价残差、曲面扭曲、供需失衡
  • 代表：曲面套利、Dispersion、GEX、Event Vol
  • 特点：夏普高但容量小
  • 容量：小（数千万至数亿）
  • 衰减：快（需持续迭代）

CHAPTER 09

标准研究流程（Pipeline）

Step 1：数据获取与美式期权定价

OPRA报价链 → 美式定价（Bjerksund-Stensland / CRR）→ 校准SOFR利率、Hard-to-Borrow Rate、预期派息 → 计算理论价与全Greeks（含Vanna、Volga、Charm）

Step 2：波动率曲面拟合

SVI截面拟合（Gatheral无套利约束）→ 跨到期日SABR动态 → 提取ATM IV、25Δ Skew、Term Slope、PC1/2/3 → 计算平滑Greeks

Step 3：因子构建与预处理

构建VRP、GEX、PCR、POP、Premium/Margin等 → 去极值（MAD）→ 标准化（Z-score）→ 中性化（剔除VIX水平影响后看Skew增量）

Step 4：单因子检验（区分对冲模式）

Delta中性检验：每天将Delta对冲归零，纯粹检验因子对Vega/Gamma收益的预测。非对冲检验：直接检验因子对策略P&L的预测。Rank IC & Straddle/Strangle回测。

Step 5：考虑执行成本的回测

滑点：卖出 Ask−Spread×0.25，买入 Bid+Spread×0.25。流动性：剔除OI<100或Spread>5%。包含：保证金变化、展期成本、早期行权。

Step 6：组合优化与TIMS约束

Reg T（15-20%固定）或PM（OCC TIMS）→ ±6%~±15% Stress Test → 计算真实Margin → Yield on Margin最大化 → 优化持仓权重

Step 7：实盘监控与归因

每日Greeks报告 → P&L归因（Δ/Γ/ν/Θ）→ VaR/CVaR → 保证金预警 → 因子衰减追踪 → 拥挤度监控

🔴 回测致命陷阱清单
  1. Mid价回测：实际在Bid/Ask，价差5-15% → 必须用Bid/Ask或加滑点
  2. 忽略流动性：深度OTM日均成交量仅10张 → 大资金无法执行
  3. 忽略保证金：卖期权需大量保证金，不足被强平
  4. 忽略早期行权：美式深度ITM + 除息 → 提前行权
  5. 忽略事件跳跃：财报/FOMC跳空无法用连续模型捕捉
  6. 忽略展期成本：月度策略每月展期，滑点累积
  7. 忽略容量：期权市场容量远小于股票市场

15.4 核心结论

1️⃣ 期权因子 ≠ 股票因子
核心是波动率曲面（水平/偏斜/曲率/期限）、Greeks、GEX、VRP、保证金效率。但91%方差被股票因子解释，增量集中在跳跃尾部、峰度、IV凸性。
2️⃣ IV曲面是核心信息载体
四维分解（水平/偏斜/曲率/期限）是基本框架。期限结构比短期水平更有信息量。中期偏度斜率携带显著正溢价。
3️⃣ VRP是Beta，曲面错价是Alpha
卖期权收VRP = Smart Beta（高胜率、胖尾）。曲面套利、Dispersion、GEX = 真正的Alpha（高夏普、小容量）。
4️⃣ 收益归因 = Greeks分解
dP ≈ Δ·dS + ½Γ·(dS)² + ν·dσ + Θ·dt + 残差。理解每一分钱来源是风控和优化的基础。
5️⃣ 风控 = Greeks + TIMS + 尾部
不是行业中性，而是Delta中性、Gamma/Vega限制、TIMS保证金、尾部对冲、流动性过滤。
6️⃣ 深度学习是独特工具
CNN提取曲面模式、扩散模型生成曲面、VAE压缩、DRL对冲。但必须直面无套利约束、稀疏性、0DTE、成本、容量。
7️⃣ 回测必须考虑期权摩擦
Bid-Ask（5-15%）、流动性、保证金、早期行权、展期成本——忽略任何一个都严重高估收益。
8️⃣ 终极原则
期权量化的核心不是预测方向，而是"定价波动率、管理Greeks、收割溢价、控制尾部"。目标不是用DL替代经济逻辑，而是将金融理论作为约束嵌入模型，构建可解释、可迭代、成本感知的研究体系。
