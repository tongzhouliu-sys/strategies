CHAPTER 01

The Wheel策略概述与有限状态机（FSM）

Wheel策略在实战中绝非简单的"定期卖Put接盘、卖Call离场"。从量化金融视角来看，Wheel策略是一个叠加了波动率风险溢价（VRP）捕获、权益因子筛选以及动态Greeks调控的非线性有限状态机（Finite State Machine, FSM）。本报告从数学建模、因子构造、Greeks演变、Portfolio Margin风控以及工业级工程架构五个维度，对Wheel策略进行深度拆解。

1.1 核心逻辑

The Wheel的本质：用卖出期权（短Theta）的方式，以低于市价的成本获取标的资产，然后以高于成本的价格卖出标的资产，循环往复，持续收取"租金"（权利金）。

阶段操作收入来源风险结果
阶段1：CSP卖出Cash-Secured Put权利金（Premium）标的暴跌→被行权→被迫接货未行权→收权利金→重复CSP；被行权→进入阶段2
阶段2：CC持有股票+卖出Covered Call权利金+股息+潜在增值标的暴涨→被行权→被迫卖出未行权→收权利金→重复CC；被行权→回到阶段1

1.2 收益来源分解

The Wheel年化收益 = 权利金收入(Theta) + 股息收入(Dividend) + 标的增值/减值 ± 滚仓损益 − 交易成本
收益来源典型贡献可控性驱动因子
权利金收入（Theta）年化8–20%高（Delta/DTE/IV选择）Theta、VRP、Skew
股息收入年化0–5%中（选股时确定）基本面
标的增值不确定低（市场决定）Delta
滚仓损益通常为正中（时机选择）IV、时机

CHAPTER 02

学术理论基础

2.1 波动率风险溢价（VRP）的学术根基

✅ VRP是The Wheel的理论基石

学术研究一致表明，隐含波动率（IV）在大多数时间范围和市场制度下系统性超过已实现波动率（RV），这一持续偏差反映了市场参与者为承担波动率风险所要求的补偿，类似于保险公司收取超过预期赔付的保费。卖权策略正是为随时间捕获这一溢价而设计。

VRP > 0 → 期权被系统性高估 → 卖出策略具有正期望收益。这是Wheel策略盈利的根本来源，也是其与纯方向性策略的本质区别。

VRP = IV − RVforward
Variance Risk Premium = VIX²/10000 − EP[RV²]

实证：VRP年化约3-5个波动率点，在高IV环境中更大（恐慌时保险溢价更高）

2.2 卖权等价性与路径依赖

维度CSPCCWheel含义

期权定价与Greeks（Wheel视角）

3.1 BSM定价公式

CSP（Put）: P = K·e−rT·N(−d₂) − S·e−qT·N(−d₁)
CC（Call）: C = S·e−qT·N(d₁) − K·e−rT·N(d₂)
d₁ = [ln(S/K) + (r−q+σ²/2)T] / (σ√T)
d₂ = d₁ − σ√T

高阶多因子打分模型

6.1 核心因子数学定义

(1) VRP Z-Score

VRPt = IV30D,t − RV30D,t
ZVRP,t = (VRPt − μVRP,252) / σVRP,252

(2) d₂安全距离

d₂ = [ln(S₀/K) + (r − q − σ²IV/2)T] / (σIV√T)
要求: d₂ ≥ 1.28（对应90%+理论OTM概率）

(3) Put Skew Slope

SkewPut = [IV(15Δ Put) − IV(50Δ ATM)] / (0.50 − 0.15)

(4) Portfolio Margin年化资金效率（ROCPM）

ROCPM = P₀ / MarginTIMS × (365/DTE)
MarginTIMS ≈ max(S₀×(0.15 − (S₀−K)/S₀), 0.10×K) + P₀

(5) Theta/Gamma效率比

EfficiencyΘ/Γ = |Θ| / (|Γ| × S₀)

6.2 综合打分公式

Scorei = w₁·ZVRP + w₂·SkewPut + w₃·ROCPM + w₄·ZQuality − w₅·βMarket

推荐权重: w₁=0.25, w₂=0.20, w₃=0.25, w₄=0.20, w₅=0.10

6.3 三级过滤流程

===== Wheel选股三级过滤 ===== Level 1: 硬性过滤（Hard Filter） ✓ Bid-Ask Spread / Mid < 2.5% ✓ Open Interest > 1,000 ✓ 距下次财报 > DTE + 7天 ✓ 市值 > $10B → 全美股 ~500 → ~200 Level 2: 质量过滤（Quality Filter） ✓ Altman Z-Score > 2.9 ✓ FCF Yield > 3% ✓ MA50 > MA200 ✓ Debt/Equity < 1.0 → ~200 → ~60 Level 3: 截面因子打分（Scoring） 计算 Z_VRP, Skew, ROC_PM, Quality, Beta Score = 0.25×Z_VRP + 0.20×Skew + 0.25×ROC_PM + 0.20×Quality − 0.10×Beta 排序 → 输出Top 8-12 → ~60 → Top 8-12

===== CSP滚仓决策树 ===== 触发条件: S_t < K_put AND DTE ≤ 7 Step 1: 评估标的是否仍适合Wheel ├── 趋势破坏（MA50 < MA200）? → 止损平仓，不滚仓 ├── 基本面恶化? → 止损平仓，不滚仓 └── 仅短期回调? → 继续评估 Step 2: 寻找可获Net Credit的滚仓 ├── Roll Down（降低行权价） │ 新K_new < K_old │ 目标: 增加安全垫 ├── Roll Out（延长到期日） │ 新DTE = 30-45天 │ 目标: 获取更多Theta └── Roll Down & Out（组合） 新K更低 + 新DTE更长 目标: 最大化安全垫+权利金 Step 3: 检查Net Credit ├── Net Credit > 0 → 执行滚仓 ✓ └── Net Credit ≤ 0 → 不滚仓，等待到期 ├── 到期时OTM → 收取全部权利金 └── 到期时ITM → 接受行权（如果愿意持有） 滚仓限制: ✗ 滚仓次数 ≤ 3次 ✗ 每次滚仓必须获得Net Credit ✗ 新行权价不得低于原始行权价的85%

7.4 成本基础管理

✅ 关键规则
  • 有效成本基础 = Put行权价 − 累计收取的权利金/100
  • 例：在$95被行权，收取$2.00权利金 → 有效成本 = $95 − $2.00 = $93
  • CC行权价绝不低于有效成本基础（否则被Call走时亏损）
  • 如果计算出的Kcall < 成本基础 → 不卖Call，持有等待
  • 每次CC收取的权利金进一步降低成本基础
===== 成本基础追踪示例 ===== CSP被行权: K_put = $95, 收取权利金 $2.00 → 成本基础 = $95 - $2.00 = $93.00 CC #1: K_call = $97, 收取权利金 $1.50 → 到期未行权，继续持有 → 成本基础 = $93.00 - $1.50 = $91.50 CC #2: K_call = $96, 收取权利金 $1.20 → 到期未行权，继续持有 → 成本基础 = $91.50 - $1.20 = $90.30 CC #3: K_call = $95, 收取权利金 $1.00 → 到期被行权，以$95卖出 → 总收益 = ($95-$90.30)×100 + $1.00×100 = +$570

9.2 Pin Risk与到期日管理

🔴 Pin Risk（钉扎风险）

到期日（DTE=0），若ST ≈ Kput，Gamma→∞，少量交易即可导致期权在ITM/OTM间剧烈摆动。若未平仓，交易者无法确认是否会被Assignment，可能导致周末暴露巨大的未经对冲的隔夜正股风险。

硬性规则：到期日当天15:00 EST前，无条件平仓所有 |ST−K|/ST < 1.5% 的合约。

9.3 除息日提前行权（Call侧特异性风险）

Extrinsic Value = Cmarket − max(0, St − Kcall)

若 Extrinsic Value < Net Dividend → 理性买方会在除息日前一交易日提前行权

规则：除息日前2天扫描该条件，若满足，提前平仓CC或Roll Up，避免正股被提前强平导致失去股息收益。

15.3 核心结论

1️⃣ The Wheel是"非线性有限状态机"
4个状态（CASH→CSP→STOCK→STOCK+CC→CASH）× 6种转移条件。每个转移都有精确的数学触发条件和执行动作。不是"定期卖Put"，而是一个动态决策系统。
2️⃣ VRP是理论基石，但不是免费午餐
IV>RV是Wheel盈利的根本来源。但VRP是对承担尾部风险的补偿——2018.02和2020.03证明了这一点。必须配尾部保护和严格止损。
3️⃣ 选股 > 选合约 > 选时机
Wheel最大的风险不是期权定价错误，而是选错标的。Altman Z>2.9、FCF Yield>3%、MA50>MA200、Beta 0.8-1.5——这些选股因子比Delta/DTE选择更重要。
4️⃣ 20Δ + 30-45 DTE是学术最优区间
深度虚值Put的Sharpe 0.90 vs 平值0.11。20-45 DTE是Theta衰减最快且Gamma可控的区间。d₂≥1.28确保90%+ OTM概率。
5️⃣ 收益封顶是Wheel的代价
SPY Wheel五年+41% vs 买入持有+129%。Wheel用收益上限换取了风险下限（-13% vs -22%）。在牛市中必然跑输，在震荡/熊市中显著优于。
6️⃣ LLM+贝叶斯网络是当前最优DL架构
15.3%年化、Sharpe 1.08、-8.2%回撤、0%行权率、27个可解释因子。LLM不直接决策，而是构建上下文贝叶斯网络——可解释性是核心竞争力。
7️⃣ 风控比收益更重要
单笔<5%、总暴露<30%、保证金<70-80%、VIX>30暂停、跌破K>10%止损、到期日15:00前平仓ATM合约。这些规则是生存的关键。
8️⃣ Kelly-VIX混合仓位管理
分数Kelly（1/4-1/2）× VIX缩放因子。VIX9D比VIX30D更能预测短期风险。低波动时缩减，高波动时暂停。
9️⃣ 终极原则
The Wheel的核心不是预测方向，而是"选好标的、卖好价格、控好风险、循环收租"。它更像一个"期权房东"——出租资本（保证金），收取租金（权利金），但必须确保"房子"（标的）不会倒塌。最终目标不是用DL替代交易纪律，而是将金融理论与因子逻辑作为约束嵌入模型，构建可解释、自适应、成本感知的Wheel策略研究体系。
