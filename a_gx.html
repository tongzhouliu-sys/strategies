五因子综合评分取代原版单一20日均线红绿灯
⚡
原版只用"指数是否站上20日线"作为唯一开关，过于粗糙。指数在20日线上方时可能市场宽度极差（只有少数权重股拉动），或板块轮动已进入尾声。本引擎用五个独立因子，综合得分决定仓位上限。

AI 智能选股系统
技术形态初筛 → 量化评分 → AI情绪验证 → 负面过滤

第一步：技术形态初筛（全自动）

以下条件全部满足方可进入候选池（Python自动筛选，无需人工）：

①
近20个交易日内出现首次涨停 排除已涨停超过3次的票（炒作过度），排除连续涨停未整理的票（买入时机过早）。涨停定义：当日收盘涨幅 ≥ 9.9%（排除ST股的±5%上限）。
②
涨停后形成向上跳空缺口且3日内未完全回补 缺口定义：涨停次日开盘价 > 涨停当日最高价。回补定义：缺口形成后3个交易日内，任意一日的最低价 ≤ 涨停日最高价。未回补则保留候选资格。
③
缺口上方出现2-7天缩量整理 缩量定义：整理期日均成交量 ≤ 涨停日成交量的60%。整理定义：高低点均在缺口上沿之上，无新高出现（否则已启动，错过最佳时机）。
④
属于"板块动能加速"的主线板块 计算各行业板块的动能加速度 = 近3日涨幅 / 近10日涨幅。取加速度排名前10的板块作为合法选股范围。比原版10日涨幅排序提前捕捉板块启动节点。

05
T+1合规入场规则
完整修复原版T+1盲区，两买点改为互斥逻辑
⚠️
T+1核心约束：所有买入操作均基于收盘后的筛选结果，次日执行。当日买入的仓位当日不可卖出。因此，止损不能设为"当日K线最低点"，必须以"收盘价"为锚点，允许次日确认，第三日执行。

入场触发条件（次日开盘前确认）

Pre
9:15 盘前确认三个"放行条件" ① 市场环境引擎综合得分 ≥ 50分（B级以上）；② 该股无临时停牌；③ 该股未触发任何新的负面过滤器（减持公告等）。三项全部满足方可下单。
A
买点A（主买点）：开盘价确认入场 开盘价在昨收 ±2% 以内（相比原版±1.5%略放宽），竞价结束后9:30立即买入 1/2标准仓位。若开盘跳空超过+2%，放弃当日买入，等候回踩。若低开超过-2%，同样放弃，等候企稳确认。
B
买点B（替代买点，与A互斥）：缺口上沿低吸 若买点A未触发（开盘超过±2%），则转为买点B：将缺口上沿价格设为限价单挂单，等候股价盘中回踩至该位置时买入1/2标准仓位。同日如果股价未触发B，当日不入场，次日重新评估。
C
加仓确认（独立于A/B之外） 初始仓位建立后，股价放量（当日成交量 > 5日均量×1.3）突破整理平台上沿，且次日开盘不破昨日收盘价，确认后追加至满仓（标准仓位的剩余1/2）。加仓后平均成本自动更新，止损位同步上移。

T+1合规止损规则（最重要的修复）

止损类型触发条件执行动作执行时间
价格止损 入场后任意收盘日，收盘价跌破入场当日收盘价的 -6%（非当日最低点！） 次日开盘前15分钟挂跌停板-2%以上的限价卖单，确保成交 确认日次日开盘
时间止损 入场后7个交易日内（扩展自原版5日），收盘价涨幅未超过 +4% 第8个交易日开盘卖出，不等待更好价格 第8日开盘
形态止损 缺口被完全回补（收盘价低于涨停日最高价） 次日开盘无条件止损，技术形态逻辑已破坏 确认日次日开盘
板块止损 所属主线板块连续2日从强势板块排名前20%跌出至后50% 次日收盘后评估，若形态仍完整可宽限1日；否则第三日开盘止损 灵活（2-3日内）
💡
T+1止损操作规程：由于当日买入不可卖出，"止损"在实操中是一个两天流程：D日确认收盘触发 → D+1日开盘执行卖出。因此选股时要更加严格，入场后第一夜的风险是无法规避的，必须通过更高的入场质量来对冲。

移动止盈阶梯（完整量化版）

浮盈区间止盈锚点触发条件（量化定义）执行动作
0%-4% 入场收盘价 × (1 - 6%) 收盘价跌破此价格 次日开盘全部止损
4%-8% 成本价（保本线） 收盘价跌破成本价 次日开盘全部止损
8%-15% 10日收盘均线 收盘价跌破10日均线当日 → 减仓1/2；次日收盘仍在10日线下方 → 清仓剩余 两步清仓
15%-25% 20日收盘均线 收盘价跌破20日均线 → 全部清仓 次日开盘止盈
25%以上 20日均线 + 暴利止盈 触发以下任意一项暴利止盈信号：
① 单日成交量 > 5日均量×1.5 且 收盘跌幅 > 4%（放量巨阴）
② 连续3个交易日收盘最高价未超过前3日最高价（量化"不创新高"）
③ 20日均线跌破		 次日开盘全部清仓
放量巨阴 = (当日成交量 > MA(成交量,5) × 1.5) AND (当日跌幅 > 4%)
连续不创新高 = MAX(High, 3) <= MAX(High[-3:-1], 3)
// 以上条件均可用Python pandas一行计算，无需人工判断

主动离场信号（额外触发，不依赖止盈线）

  • 所属主线板块当日涨跌家数全面逆转：原主线板块当日跌幅超过1.5%，且全市场涨跌比 < 0.5，无论盈亏直接离场
  • 持股期间出现新增减持公告或ST预警，无论盈亏，次日开盘无条件清仓
  • 市场环境引擎当日跌入D级（0-24分），所有持仓次日逐步清仓（允许2日内完成，避免集中踩踏）

仓位管理与账户风控

单票最大仓位
30%
A级市场状态下上限，B级降至20%
最多同时持仓
3支

1/2

三级熔断机制（修复原版高点定义不清问题）

高点定义：每日收盘后计算账户总市值，取过去60个自然日内的最高收盘净值作为高水位线。回撤基于此滚动高水位线计算，不使用盘中价格。

L1 · 预警熔断（回撤 5%）

触发条件
  • 账户收盘净值 / 60日高水位 ≤ 0.95
  • 连续2日满足即触发（单日可能是正常波动）
    • 强制动作
  • 次日开始禁止新开仓
  • 现有持仓止损位全部上移一档
  • 当日推送飞书预警通知

    • L2 · 强制减仓（回撤 7%）

    触发条件
  • 账户收盘净值 / 60日高水位 ≤ 0.93
  • 当日收盘即触发，无需连续确认
    • 强制动作
  • 次日开盘卖出盈利最少的持仓，总仓位降至50%以下
  • 禁止新开仓，直至回撤恢复至5%以内
  • 审查各持仓是否需要提前止损

    • L3 · 无条件清仓（回撤 10%）

    触发条件
  • 账户收盘净值 / 60日高水位 ≤ 0.90
  • 当日收盘即触发
    • 强制动作
  • 次日开盘全部清仓，不留任何仓位
  • 强制空仓复盘期：最少10个交易日
  • 复盘期结束后，重新完成市场环境评分，方可重新开仓

    AI 决策辅助层
    DeepSeek API 四个接入点，全部为辅助角色，不替代规则判断
    AI-01 每日市场环境简报

    每日15:30自动触发。将五因子得分数据、北向资金、两融变化、涨跌比、主要指数K线特征喂入DeepSeek，生成约200字的市场环境判断，包括主要风险点和次日需关注的事件。推送至飞书。

    AI-02 个股舆情情绪打分

    对进入候选池的每支股票，拉取近7日新闻标题和公告摘要，喂入DeepSeek，要求返回0-8分的情绪评分和关键风险点。此分数计入量化评分模型AI情绪维度。

    AI-03 持仓健康诊断

    每日收盘后，将当前持仓状态（入场价/现价/浮盈/止损位/持仓天数/板块状态）喂入AI，要求逐票输出"继续持有/关注/建议止损"三档建议及原因。人工参考后决策。

    AI-04 周度复盘归因分析

    每周五收盘后，将本周所有已平仓交易（入场原因/出场原因/盈亏/市场状态）喂入AI，要求识别盈亏模式、执行偏差、参数调整建议。形成可迭代的策略进化闭环。

    每日 SOP 操作流程
    全自动化任务 + 人工决策节点清单

    收盘后（15:00 - 17:30）

    ⚙️
    15:05数据采集脚本启动（自动）

    GitHub Actions触发。拉取当日行情、涨停数据、北向资金、两融余额、板块涨跌。约2分钟完成。

    🔢
    15:08市场环境引擎计算（自动）

    计算五因子得分，判断市场级别（A/B/C/D），确定次日最高可用仓位上限。

    🔍
    15:12技术形态筛选（自动）

    全市场扫描：涨停+缺口+缩量整理+板块动能加速度。通过负面过滤器（ST/减持/商誉）。生成候选池（通常5-20支）。

    🤖
    15:20AI舆情评分（自动）

    对候选池每支股票调用DeepSeek API，获取情绪分。候选池 > 10支时，先用量化分过滤至前10，再做AI评分节省token。

    📊
    15:30综合评分排序 + 飞书推送（自动）

    合并量化评分+AI情绪分，取top 3-5支，生成结构化信号卡片推送飞书。同时推送当日市场环境简报和持仓诊断。

    👤
    17:00人工复核（必须）

    查看飞书推送的信号卡片。逐支确认：① 图形是否符合预期 ② 板块逻辑是否成立 ③ 是否有系统未识别的风险。最终确定次日实际操作名单（通常1-3支）。

    次日盘前（9:00 - 9:30）

    🌅
    9:00早间风险扫描（自动）

    重新检查昨晚至今的减持公告、停牌公告、重大事项。如有新增，立即从操作名单剔除。

    📋
    9:20核对盘前条件（人工，3分钟）

    确认昨日收盘止损是否需要今日执行。确认市场期货（IF/IC）走势，判断今日开盘方向。准备好对应的挂单价格。

    ⚡
    9:25集合竞价观察（人工）

    观察目标股竞价情况。若竞价结果在±2%以内，准备9:30买点A入场。若竞价大幅偏离，启动买点B限价挂单逻辑。

    ✅
    9:30执行开仓或止损（人工）

    按照前一日确定的计划执行。新仓买入1/2标准仓位。已触发止损的仓位优先处理（T+1约束下，当日买入的不可卖，其余正常止损）。

    持仓期间（每日收盘后5分钟）

    • 检查每个持仓的收盘价是否触发移动止盈阶梯的任一止损线
    • 检查是否触发账户级别熔断（L1/L2/L3）
    • 查看AI-03持仓健康诊断推送，作为参考（非执行依据）
    • 检查是否有加仓确认信号（放量突破平台，明日可追加）
    • 更新交易台账：记录当日高低收盘价和持仓天数

    铁律红线
    永不触碰的绝对边界，无论市场如何诱惑
    RL-01 AI建议不得直接触发买卖指令。
    DeepSeek的任何输出只作为参考信息，实际买卖决定必须经人工确认。系统不设任何全自动交易路径。
    RL-02 市场环境D级时，禁止任何新开仓操作。
    即使信号评分再高，市场环境不支持时不得入场。只能维护现有止损。
    RL-03 买入ST/退市警示股票，零容忍。
    无论评分多高，无论是否通过技术分析认为图形强势，ST股票一律排除在外。
    RL-04 L3熔断触发后，不得在空仓复盘期（10个交易日）内以任何理由重新开仓。
    市场"看起来好转"不是理由。必须完成10日复盘，并重新完整计算市场环境评分后方可重开。
    RL-05 单日亏损超过总资金2%时，当日停止所有新操作。
    亏损扩大后的情绪状态不适合继续交易，强制冷却，次日复盘后重新评估。
    RL-06 不做量化评分低于75分的票，哪怕AI情绪分很高。
    AI情绪加分是加分项，不能用来弥补基础量化分的不足。基础分不过线就是不合格。
    RL-07 T+1止损两天流程不得因"感觉明天会反弹"而延迟执行。
    D日确认收盘破位 → D+1日必须开盘止损。这条纪律是整个系统最重要的执行纪律。
